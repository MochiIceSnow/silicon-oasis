# Silicon Oasis 《硅基绿洲》

> A cozy post-apocalyptic base-builder about grafting e-waste into living plants.

**Status: pre-production.** No playable build yet. Watch this repo for updates.

---

## What is this

Drive a small cart through the wastes, scavenge electronic scrap, find abandoned laboratories, and splice that scrap together with ordinary plants into half-mechanical symbionts. Then wire them up with node posts and keep a glowing ecological grid alive.

**Core loop**

```
Scavenge  →  Repair the lab  →  Splice genes  →  Build the power grid  →  Keep the balance
```
